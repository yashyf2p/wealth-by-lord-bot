# Wealth By Lords Discord Bot

## Setup

1. Install Node.js 18 or newer.
2. Copy `.env.example` to `.env`.
3. Put your NEW Discord bot token in `.env`.
4. Open a terminal in this folder.
5. Run:
   npm install
6. Start the bot:
   npm start

Then in Discord use:

/send channel:#your-channel message:Hello

The `/send` command is restricted to Discord administrators by default.

IMPORTANT: Never upload or commit your `.env` file.
